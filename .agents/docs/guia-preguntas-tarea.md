# Guía: Qué Información Dar al Asignar una Tarea a la IA

## Información mínima

- [ ] Qué se necesita (resultado esperado)
- [ ] Artefacto de análisis relacionado (`docs/analisis/...`) si existe
- [ ] App/módulo (`backend`, `mobile-pasajero`, `mobile-conductor`, `web-admin`)
- [ ] Modo: desarrollo / análisis / calidad

## Por tipo

### Feature

```
Necesito [QUÉ]:
- Entidad/campos
- Reglas de negocio
- Validaciones
- Errores posibles
- Acceptance criteria / EU
```

### Bug

```
Bug: [corto]
- Esperado / Actual
- Pasos
- App / archivos sospechosos
```

### QA

```
QA de [feature/EU]:
- ¿Solo plan, o plan + Playwright + evidencia?
- ¿App bajo prueba?
```
