# Modo Análisis

Activa las reglas y guías para tareas de análisis de requerimientos: elicitación, calidad, definition of ready, estructura de datos y documentación local en `docs/analisis/`.

En TripTap, el análisis se **extrae del código legacy** (ver `migracion-extraccion-legacy.md`) y se guarda en `docs/analisis/sistema|inventario|escenarios|…`.

Cuando el usuario elija **modo Análisis**, lee y aplica estas rules del proyecto:

- `.agents/rules/migracion-extraccion-legacy.md`
- `.agents/rules/analisis-destino-local.md`
- `.agents/rules/analisis-rol-analista-requerimientos.md`
- `.agents/rules/analisis-elicitacion-requerimientos.md`
- `.agents/rules/analisis-estandares-calidad-requerimientos.md`
- `.agents/rules/analisis-definition-of-ready.md`
- `.agents/rules/analisis-flujo-completo-post-levantamiento.md`
