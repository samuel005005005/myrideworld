# Skills del Proyecto

Skills organizados por fase del ciclo de desarrollo.

## Desarrollo (`dev-`)

| Skill | Descripción |
|-------|-------------|
| `dev-aws-services` | Guía para servicios AWS (S3, Lambda, CloudFront, etc.) |
| `dev-bitacora-auditoria` | Patrón de bitácora de auditoría en BD |
| `dev-clean-architecture` | Generación de código siguiendo Clean Architecture |
| `dev-plan-implementacion` | Crear planes de implementación locales |
| `dev-proceso-ejecucion` | Tracking de procesos batch en BD |
| `dev-unit-testing` | Generación de tests unitarios con convenciones del equipo |

## Análisis (`analisis-`)

| Skill | Descripción |
|-------|-------------|
| `analisis-documentacion-escenarios` | Documentar escenarios, métodos, modelos y estructuras en `docs/analisis/` |
| `analisis-requirements-engineering` | Descubrimiento guiado de requerimientos y artefactos locales |

## Uso

Los skills se activan bajo demanda cuando coinciden con la tarea, o puedes invocarlos explícitamente.
